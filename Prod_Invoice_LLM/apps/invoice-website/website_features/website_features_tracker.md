  **Total solution, end to end (so this is rebuildable from this description alone):**
  1. **Two entry points, both in `FlowsShowcaseSection.tsx`**: a "Launch Live Simulator" button (`onClick={() => onOpenModal("inbound")}`) that opens `FlowsModal` pre-selected to the Inbound flow, and a "Full Tab" `<a href={flowsUrl} target="_blank">` that navigates away entirely.   2. **`FlowsModal.tsx` is the shared viewer**: computes `flowsUrl = \`${FE_URL}/flows${initialFlowId ? \`?flow=${initialFlowId}\` : ""}\`` where `FE_URL = process.env.NEXT_PUBLIC_FE_URL || "http://localhost:3001"`. Renders this URL two ways simultaneously — a live `<iframe src={flowsUrl}>` for in-page preview, and an "Open Full Screen in New Tab" `<a href={flowsUrl} target="_blank">` for the same URL.
