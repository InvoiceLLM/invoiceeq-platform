  **Total solution, end to end (so this is rebuildable from this description alone):**
  1. **Two entry points, both in `FlowsShowcaseSection.tsx`**: a "Launch Live Simulator" button (`onClick={() => onOpenModal("inbound")}`) that opens `FlowsModal` pre-selected to the Inbound flow, and a "Full Tab" `<a href={flowsUrl} target="_blank">` that navigates away entirely.
