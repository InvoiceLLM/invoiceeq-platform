# Development Rules

- **Workflow Steps**: For any task, follow this sequence:
  1. Read the feature specification file.
  2. Analyze the current code and identify the exact code additions/modifications needed.
  3. Check the progress tracker file for any missing items or related gaps.
  4. Code **one file at a time**, presenting proposed changes and waiting for explicit user approval on the lines changed.
  5. Update the progress tracker file once changes are approved and written.
- Work on exactly one feature tracker task at a time. Do not multi-task across features.
- Keep all discussions, queries, and file updates strictly limited to the current active feature context.
- Present changes for approval and wait before editing other files or executing commands.
